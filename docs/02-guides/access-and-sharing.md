# 私有访问、受限分享与演示

默认主机 API、最新指标和 SSE 必须登录；空间从会话身份读取。省略 tenant 只读取自己的空间，指定其他空间返回 403；未登录返回 401，任意 hostUID 不会扩大授权范围。Web 看板、成员和分享管理使用相同登录守卫，错误空间与管理员权限不足有专用状态。

## 创建和撤销分享

管理员进入 `/<tenantCode>/shares`，选择当前空间主机（1～100 台）、有效期（最长 7 天）及允许字段：

- `hostname`：可读主机名称。
- `status`：主机/Agent/服务状态、最后上报/探测时间、活动告警数和版本。
- `metrics`：16 项固定摘要值、采样时间和短期摘要历史；仅在实际存在采样时间时显示值。

稳定主机标识 `host_uid` 始终包含，用于区分被选中的主机及流式增量；它不构成私有 API 的访问凭据。分享永远不公开 IP、租户编码、分组/标签、动态设备/挂载点/网卡维度、采集器明细。未分享指标不会被展示为零值。管理员列表包含到期和撤销状态，凭据只在创建时返回一次。

接收链接形如 `/share#token=<随机凭据>`；fragment 不进入 HTTP 请求、Referer 或服务端访问日志，前端在加载时立即从当前浏览器历史项移除，再通过 POST body 兑换专用会话。原始 token 和兑换后的会话只在数据库保存 SHA-256，不使用 localStorage 或持久私有缓存。临时兑换失败可在当前页面重试，原始凭据只保留在组件内存至兑换成功；永久拒绝或离开页面后不再保留。

兑换接口 `POST /master/api/v1/public/shares/exchange` 要求合法 Origin、JSON 和有界请求体。Cookie `gaoming_share` 为 HttpOnly/SameSite=Lax，路径限定 `/master/api/v1/public/shares`，与私有 `gaoming_session` 无关；它不能登录、管理用户、创建维护窗或确认告警。生产跟随 `session_cookie_secure: true`。同一浏览器的新分享会替换该 Cookie。

撤销、新请求到期或创建者被禁用/降级、租户被停用后，旧会话不可读取；SSE 每秒重验、发送增量前再次重验，权限查询最多等待 2 秒，写入最多等待 5 秒。关闭流不会撤回已经传送的字节。接收页连接中断会隐藏分享数据，并提供重新验证入口；没有足够权限时显示分享失效状态。

每个空间最多保留 100 条分享记录（含过期/已撤销记录），每条分享最多 100 个有效兑换会话；超额返回 429。兑换时清理该分享的到期会话，撤销删除其所有会话但保留分享和审计记录。尚未开放分享历史删除功能；生命周期清理需在后续运营任务中扩展。主机删除由 FK 清除分享关联，不会使分享包含其他主机。

## 显式演示配置

演示默认关闭；不能仅填写租户编码就开放全量主机。必须同时配置准确主机集合和允许字段：

```yaml
demo_tenant_code: demo
demo_host_uids:
  - demo-host-1
demo_fields:
  - status
  - metrics
```

入口 `/demo`，API 为 `/master/api/v1/public/demo/...`。白名单规则与分享相同；配置不完整、未知字段、重复主机或超过 100 台会拒绝启动。演示租户必须存在且启用，GET 中的 tenant/hostUID 不得扩大配置范围。演示授权来自部署管理员配置，不由匿名用户修改。配置修改需重启服务；私有数据不得因猜到租户名而被标为演示。

## 运维写入

维护窗仅管理员可创建；scope_type 允许 `tenant`（scope_ref 为自己的 tenantCode）、`host`（自己空间的 hostUID）、`group`（自己空间的 groupCode）。标题、范围、时间和文本有边界，结束须在未来，单窗最长 30 天。当前步骤只提供安全写入，不代表告警抑制已生效，抑制与维护列表/编辑属于 T12。

告警确认允许管理员/成员，只接受自己空间实际存在的数字 ID。确认重试保留首位操作者，不重复产生成功审计。CreatedBy/AckedBy 请求字段不作为身份；数据库检查当前用户/租户状态和角色，写入与成功审计在同一事务提交。资源不存在或跨空间都返回 404。

## 开发验证与升级

先执行 `make migrate`，应用 004 access-shares；禁止修改已发布迁移或删除数据卷。`make smoke-agent` 现在要求 `SESSION_COOKIE_FILE` 指向已登录 Cookie jar，不能继续使用匿名读取。`make docker-smoke` 自动建立独立数据库、临时管理员和权限 0600 的 Cookie/JSON 文件，验证匿名拒绝及授权 Agent 链路后清理自己的项目；不会读取或删改现有部署卷。

使用 Vite 代理做 HTTP 本地联调时，master 配置必须显式关闭 Secure，并把浏览器实际 Origin 加入允许列表，例如 `http://localhost:5173` 或 `http://127.0.0.1:5173`（两者是不同 Origin）。代理的目标 Host 不等于浏览器 Origin，不能靠可信转发头自动放行。生产应保留 Secure 并配置自己的准确 HTTPS Origin。

本步骤尚未完成 Agent/worker 上报认证、TLS/生产网络边界、SSE 快照/订阅衔接和带租户删除事件。既有无租户删除通知保持丢弃，避免泄露其他空间主机；删除收敛在 T09/T18 交付。旧的非运行时 memory/master 仓储在 T10 收敛，不是私有 API 的装配入口。
